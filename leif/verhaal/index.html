Gebruik de toegangscode van LEIF. Daarna kun je het volledige persoonlijke verhaal lezen en de opdrachten invullen.

Dit is een proef met één korte toegangscode voor heel LEIF. Een korte code is geen sterke beveiliging van persoonlijke informatie. Deel de link en de code niet verder. Met Bewaar download je een versleuteld bestand dat je later zelf weer kunt openen. Je antwoorden worden niet naar de website gestuurd.
