Welkom bij LEIF

Voer je persoonlijke code in. Je antwoorden, oefeningen en verslagen staan in je eigen omgeving. Je kunt later verdergaan.

De code wordt niet herkend.

De code is persoonlijk. Deel haar niet met anderen. De LEIF-beheerder van jouw groep kan je antwoorden en verslagen inzien om je persoonlijke reactie te schrijven. De beheerder kan ook je toegang herstellen of intrekken.

LEIF-proef: gebruik uitsluitend testgegevens. De beheerder kan je antwoorden lezen.
