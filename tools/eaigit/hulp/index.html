Een lokaal bestand werkt op de computer waar je het opent. Een kopie op een ander apparaat is een afzonderlijke versie. HTML kan beperkingen hebben bij openen via file://; sommige toepassingen hebben internet, installatie of een lokale server nodig. EAIgit leest alleen en schrijft niets naar GitHub. Rechten van andere hulpmiddelen hangen af van de koppeling en je account. Voor wijzigingen en publicatie is afzonderlijke toestemming nodig. Over toegangsbeveiliging op GitHub.

ChatGPT verbinden met GitHub (optioneel)

Je kunt EAIgit zonder ChatGPT gebruiken. Wil je in een ChatGPT-gesprek rechtstreeks je repository laten onderzoeken? Verbind dan GitHub met ChatGPT.

  1. Open in ChatGPT Instellingen → Plug-ins en zoek GitHub.
  2. Installeer of verbind de plug-in en geef op GitHub alleen toegang tot de repositories die je nodig hebt.
  3. Noem je repository in de chat en vraag bijvoorbeeld om een controle van de README en de startbestanden.

Abonnement: voor EAIgit zelf is geen ChatGPT-account nodig. De plug-incatalogus bestaat op alle abonnementen, maar GitHub is niet voor iedereen op dezelfde manier beschikbaar. Controleer de rechten in je account en werkruimte. Codex is ook op Free en Go beschikbaar; Codex Cloud niet op die abonnementen.

De gewone GitHub-app in ChatGPT leest code. Voor code schrijven en publiceren heb je Codex of een andere bevoegde omgeving nodig. Laat wijzigingen beoordelen via een aparte branch en pull request.
