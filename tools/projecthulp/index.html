                        Wat hebben we niet gecontroleerd?
                          Optioneel: voorbeeldbestanden voor GitHub

                          Je kunt een voorbeeld van een README en een .gitignore opslaan als je project die nog nodig heeft.

                          Wil je ChatGPT of Codex het volgende werk laten doen?

                          Je hebt hiervoor niet verplicht een ChatGPT-koppeling nodig. Met de GitHub-koppeling kan ChatGPT de toegestane repository lezen. Voor code aanpassen en een pull request maken gebruik je Codex of een andere GitHub-omgeving met schrijfrechten.

                          1. Open ChatGPT en ga naar Instellingen → Plug-ins → GitHub. Kies Installeren of Verbinden, voor zover beschikbaar op jouw account.
                          2. Meld je aan bij GitHub. Kies de repository die je wilt laten lezen. Lees welke rechten worden gevraagd en bevestig alleen de noodzakelijke toegang. Officiële uitleg over GitHub koppelen.
                          3. Wil je code laten wijzigen? Open Codex op het web, log in en volg daar de aanwijzingen om toegang tot de juiste repository te geven. Voor Codex Cloud moet je account hiervoor in aanmerking komen. Dit is niet hetzelfde als de alleen-lezen-koppeling van ChatGPT.
                          4. Kopieer de opdracht hieronder. Controleer het voorstel, de tests en de wijzigingen voordat je een pull request laat samenvoegen. Controleer of jouw abonnement Codex Cloud ondersteunt.
                          Ook automatische controles in GitHub gebruiken?

                          We kunnen een controlebestand maken dat bij latere wijzigingen JavaScript- of Python-syntaxis nakijkt. Dit is geen volledige test van je project. Jij beoordeelt het bestand en voegt het zelf via GitHub toe onder .github/workflows/projectcontrole.yml. Pas daarna gaat GitHub Actions draaien.
