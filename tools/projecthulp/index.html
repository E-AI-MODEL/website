STAP 2 VAN 3

Welke bestanden heb je al?

Je kiest een ZIP-bestand zodat we de inhoud op je eigen apparaat kunnen onderzoeken. We sturen het niet naar GitHub. Een openbare repository lezen we rechtstreeks bij GitHub.

Alleen openbare repositories, zonder aanmelden.
Alleen in je browser gelezen. GitHub pakt een geüpload ZIP-bestand niet vanzelf uit.
◯Jij bepaalt wat later openbaar mag worden. We voeren niets uit, sturen geen projectbestanden weg en veranderen niets in GitHub.
